# نظام التنبؤ بسداد القسط الجامعي

نظام تعلم آلي وواجهة ويب للتنبؤ باحتمالية سداد الطالب للقسط الجامعي في موعده، مع تقدير عدد أيام التأخير المتوقعة عند توقع عدم السداد في الموعد.

المشروع مبني باستخدام Python وPandas وscikit-learn وFastAPI، وتعرض الواجهة باللغة العربية من اليمين إلى اليسار.

## فكرة المشروع

يستخدم النظام بيانات أكاديمية ومالية وسلوكية وسكنية للطالب من أجل تنفيذ مهمتين:

1. **تصنيف الحالة المالية المتوقعة**:
   - `1`: من المتوقع سداد القسط في الموعد.
   - `0`: من المتوقع التأخر عن السداد.
2. **الانحدار لتقدير مدة التأخير** بالأيام للطلاب المتوقع تأخرهم.

النتيجة المعروضة في الواجهة تتضمن:

- احتمالية السداد في الموعد كنسبة مئوية.
- عدد أيام التأخير المتوقع.
- رسالة توضيحية تساعد على المتابعة واتخاذ القرار.

> النتائج تقديرية ومخصصة للدعم والتحليل التعليمي، ولا تمثل قرارًا ماليًا نهائيًا.

## التثبيت والتشغيل

من داخل مجلد المشروع:

### 1. إنشاء البيئة الافتراضية

على Windows PowerShell:

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
```

إذا كانت البيئة موجودة مسبقًا، يكفي تفعيلها:

```powershell
.\venv\Scripts\Activate.ps1
```

### 2. تثبيت الاعتماديات

```powershell
pip install fastapi uvicorn python-multipart jinja2 pandas numpy scikit-learn matplotlib seaborn openpyxl
```

### 3. تشغيل التطبيق

```powershell
uvicorn app:app --reload
```

بعد التشغيل افتح:

```text
http://127.0.0.1:8000
```

توفر FastAPI أيضًا توثيقًا تفاعليًا للمسارات على:

```text
http://127.0.0.1:8000/docs
```

يجب تشغيل الأمر من مجلد المشروع الرئيسي حتى يتمكن التطبيق من العثور على مجلدي `models` و`templates`.

## خط سير البيانات

### 1. اكتشاف البيانات

يشغّل الملف `01_data_discovery.py` الفحوصات التالية على ملف `data/مجموعة البيانات.xlsx`:

- أبعاد مجموعة البيانات وعدد الصفوف والأعمدة.
- أسماء الأعمدة وأنواع البيانات.
- القيم المفقودة ونسبتها.
- السجلات المكررة.
- الإحصاءات الوصفية للمتغيرات الرقمية.
- تكرارات المتغيرات الفئوية.
- توازن فئات متغير الهدف.
- رسوم تساعد على كشف القيم الشاذة ومشكلات القياس.

وينتج الرسم `data_discovery_report.png`.

### 2. التنظيف والمعالجة المسبقة

يشغّل الملف `02_data_cleaning_and_preprocessing.py` العمليات التالية:

- قراءة ملف Excel الأصلي.
- إزالة المسافات الزائدة من أسماء الأعمدة.
- حذف عمود الطابع الزمني وعمود القسط الفارغ.
- تنظيف النصوص والقيم الفارغة.
- توحيد تصنيفات الفروع وتصحيح قيمة السكن `أجار` إلى `ايجار`.
- معالجة القيم الصفرية أو غير المنطقية والقيم الشاذة.
- تحويل المعدل المدخل من سلم 4 إلى سلم 100 عند الحاجة.
- تعويض القيم الرقمية بالوسيط والقيم الفئوية بالمنوال.
- إنشاء هدف التصنيف `target_class`.
- إنشاء هدف الانحدار `target_delay_days`.
- تطبيق الترميز الترتيبي والثنائي وOne-Hot Encoding.
- حفظ النتائج في:
  - `data/data_cleaned.csv`
  - `data/data_preprocessed_encoded.csv`

### 3. التدريب والتقييم

يشغّل الملف `03_modeling_and_evaluation.py` العمليات التالية:

- تقسيم البيانات إلى تدريب واختبار بنسبة 80/20 مع Stratification.
- تحجيم البيانات باستخدام `StandardScaler`.
- حساب Mutual Information لاختيار وتحليل أهم الميزات.
- تدريب ومقارنة نماذج التصنيف التالية:
  - Logistic Regression
  - Decision Tree
  - Random Forest
  - SVM
  - KNN
  - Naive Bayes
  - Nearest Centroid
- التقييم باستخدام Accuracy وPrecision وRecall وF1 Score.
- اختيار النموذج الأفضل وفقًا لمقياس F1.
- إجراء تحقق متقاطع Stratified 5-Fold.
- تدريب `RandomForestRegressor` على الحالات التي تحتوي على تأخير فعلي.
- تقييم نموذج الانحدار باستخدام MAE وRMSE.
- حفظ النماذج في مجلد `models`.

الرسوم الناتجة:

- `top_features_importance.png`
- `classification_models_comparison.png`
- `confusion_matrix_best_model.png`

## واجهة التطبيق

توجد الواجهة في `templates/index.html` وتستخدم `static/style.css` للتنسيق.

يتم إدخال البيانات على أربع مراحل:

1. المعلومات الأكاديمية.
2. المعلومات المالية.
3. السكن والتنقل.
4. السلوك السابق والالتزام، ثم مراجعة البيانات.

الحقول التي ترسلها الواجهة إلى المسار `/predict` هي:

- الفرع الأكاديمي.
- السنة الدراسية.
- المعدل التراكمي.
- نسبة الحضور.
- الساعات المسجلة.
- قيمة القسط.
- الدخل الشهري.
- المسؤول عن الدفع.
- عدد الأشخاص العاملين في الأسرة.
- عدد الإخوة في جامعات خاصة.
- المحافظة.
- طبيعة السكن.
- المسافة عن الجامعة.
- مرات التأخير السابقة.
- مرات الالتزام السابقة.
- العمل بجانب الدراسة.
- التأخر السابق.
- الأقساط السابقة غير المسددة.

## مسارات FastAPI

### `GET /`

يعرض صفحة النموذج الرئيسية.

### `POST /predict`

يستقبل بيانات النموذج، ثم:

1. ينشئ صفًا جديدًا بنفس ترتيب أعمدة التدريب.
2. يحول المتغيرات الترتيبية والثنائية والفئوية إلى تمثيل رقمي.
3. يمرر البيانات إلى نموذج التصنيف.
4. يحسب احتمالية السداد في الموعد.
5. يستدعي نموذج الانحدار لتقدير التأخير إذا كانت نتيجة التصنيف هي التأخر.
6. يعيد صفحة الواجهة مع النتيجة.

عند تغيير البيانات الأصلية أو منطق التنظيف، شغّل الملفات بالترتيب التالي من المجلد الرئيسي:

```powershell
python 01_data_discovery.py
python 02_data_cleaning_and_preprocessing.py
python 03_modeling_and_evaluation.py
```

بعد انتهاء التدريب، أعد تشغيل تطبيق FastAPI للتأكد من تحميل ملفات النماذج الجديدة.

## ملاحظات مهمة

- يجب أن تتطابق أسماء الأعمدة وترتيبها بين مرحلة التدريب وملف `feature_columns.pkl` وبيانات الإدخال في `app.py`.
- ملفات `.pkl` مرتبطة بإصدارات Python وscikit-learn التي تم إنشاء النماذج باستخدامها؛ يفضل استخدام نفس الإصدارات عند تشغيل التطبيق.
- لا تحذف ملفات النماذج إذا كان الهدف تشغيل الواجهة فقط.
- ملف البيانات الأصلي يحتوي على بيانات تعليمية ومالية، لذلك يجب التعامل معه وفق سياسات الخصوصية المناسبة.
- مجلد `venv` بيئة محلية ولا يلزم مشاركته عند نقل المشروع؛ يمكن إعادة إنشائه باتباع خطوات التثبيت السابقة.
